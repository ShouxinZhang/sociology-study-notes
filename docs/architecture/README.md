# 仓库架构

各结构之间的联系由人工维护描述。但也可能有人工智能辅助描述。

`self-cultivation/虚拟朋友圈/random-writing/weekly` 毫无疑问是我主要维护的日记随笔。

`self-cultivation` 大概是自我clone 的意思。总之，一块我自己的虚拟宇宙，我可以自由的CRUD一切。

`notes` 里是2026上半年思考的一些内容，有些AI成分比较高，可读性很差。但是大体上，包含了许多我旧的思考。

`draft-notes` 我一直想要和 `notes` 合并，但是没想好该如何合并。主要是AI成分多的缘故，贸然合并我担心影响质量。草稿笔记当初创建的时候可能就是`notes`的草稿，但是后面似乎也变成类似于`notes`的模块了。

`self-cultivation/前沿BFS` 里记录了各种英文内容的中文翻译，算是悦读的一部分吧。

`self-cultivation/book_reading`，这里似乎是之前阅读哪本书来着的，反正，呃，书是很好的，但是AI胡乱创作的内容质量一般。

`self-cultivation/娱乐沙盒`，娱乐沙盒，融合了娱乐和沙盒两个重要元素，是很多元缤纷的一个模块。

`self-cultivation/自然科学研究`：自然科学研究, 基本上目前来看，以各种随心记录为主，数学当然是主线，但随时也可能记录别的。主要是当时希望有一个解耦的，单独记录数学随笔的模块，和weekly随笔解耦，但后来感觉，太麻烦了，还不如集成在weekly随笔里，而且本地隔壁的filter-theory仓库成新的数学笔记主力数据湖了

`self-cultivation/社会科学研究`：社会科学研究，是后来于notes 的单独解耦模块。notes是半年前创建的，主要在AI协助下记录一些我的想法。基本上你可以认为，notes是随笔的前身，社会科学研究是一个新的试图规范化管理的模块

`self-cultivation/天赋探索`：天赋探索，基本上是我和AI对话，根据我的历史数据，来看看我在哪些地方有天赋，特别是我没有注意到的隐藏天赋。目标就是，看看是不是说，我有一些异于常人的地方，基本上你可以认为这是基于“世界一流”的指导思想

`self-cultivation/古文学习`：古文学习，来源是我觉得古人的诗赋文言非常好，吟诗作赋是人语文能力的展现，同时还可以学习古人的智慧。从各类古文中，可以看到历史上人们的思想，知道原来自己的某些想法，早在许久之前，就有人抒发过了，还可以看到历史上人们沉淀下来的思想精华。self_write基本就是，以辞典华丽，抒发情感，阐述自然科学与社会科学理论等为主，大部分是我作一个开头，或者胡乱书写几句seed，AI予以补全，我进行二次审阅摘录

`docs/知识库`：docs/知识库，用于解释一些名词，因为我发现，AI经常不理解我书写的一些名词，这样我和它对话，它不能和我真正对齐，所以我需要解释一下。另一方面，这个仓库是我个人的数字clone，也是方便后来的智能能够彻底理解我

`docs/tempSave`：docs/tempSave，tempSave就是临时保存一些，我担心删除了很麻烦，需要备份的内容，仅此而已
