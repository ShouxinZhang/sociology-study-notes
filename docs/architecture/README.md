# 仓库架构

各结构之间的联系由人工维护描述。但也可能有人工智能辅助描述。

`self-cultivation/虚拟朋友圈/random-writing/weekly` 毫无疑问是我主要维护的日记随笔。

`self-cultivation` 大概是自我clone 的意思。总之，一块我自己的虚拟宇宙，我可以自由的CRUD一切。

`notes` 里是2026上半年思考的一些内容，有些AI成分比较高，可读性很差。但是大体上，包含了许多我旧的思考。

`draft-notes` 我一直想要和 `notes` 合并，但是没想好该如何合并。主要是AI成分多的缘故，贸然合并我担心影响质量。草稿笔记当初创建的时候可能就是`notes`的草稿，但是后面似乎也变成类似于`notes`的模块了。

`self-cultivation/前沿BFS` 里记录了各种英文内容的中文翻译，算是悦读的一部分吧。

`self-cultivation/book_reading`，这里似乎是之前阅读哪本书来着的，反正，呃，书是很好的，但是AI胡乱创作的内容质量一般。

`self-cultivation/娱乐沙盒`，娱乐沙盒，融合了娱乐和沙盒两个重要元素，是很多元缤纷的一个模块。
