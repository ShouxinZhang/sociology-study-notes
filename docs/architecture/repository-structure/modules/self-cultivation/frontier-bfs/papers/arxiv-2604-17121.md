# paper.arxiv.2604.17121

## 模块说明

arXiv:2604.17121《The Topological Trouble With Transformers》资料、官方 TeX 源码归档与完整中文 TeX/PDF 译文叶子模块

## 结构明细

| 相对路径 | 说明 |
|---|---|
| `resources/2604.17121.pdf` | 从 arXiv 下载的 v3 原始 PDF |
| `resources/2604.17121-source.tar.gz` | 从 arXiv e-print 下载的官方 TeX 源码压缩包 |
| `resources/2604.17121_abs.html` | arXiv 摘要页本地归档，用于版本、作者、摘要、许可与源码入口追溯 |
| `source/metadata.md` | 论文元信息、源码可用性、本地资源与翻译边界归档 |
| `source/` | arXiv e-print 原始 TeX 源码、BibTeX 文献库、图表 PDF 资源与原 PDF 文本层 |
| `tex-zh-cn/` | 中文 TeX 翻译工作区，复用官方图表 PDF 与 BibTeX，按摘要、正文、方向、结论分节维护 |
| `tex-zh-cn/main.tex` | 中文译稿主入口，装配 preamble、摘要、Section 1-6 与参考文献，避免主文件臃肿 |
| `tex-zh-cn/sections/` | 按摘要、引言、状态追踪、循环架构、架构局限与权宜方案、有前景方向、结论致谢拆分的完整中文正文 |
| `tex-zh-cn/main.pdf` | 编译生成的 15 页中文 PDF，保留原论文可见结构、Figure 1-7、Table 1、致谢与参考文献 |
