| 相对路径 | 说明 |
|---|---|
| `resources/2607.00272.pdf` | 从 arXiv 下载的 v1 原始 PDF |
| `resources/2607.00272-source.tar.gz` | 从 arXiv e-print 下载的官方 TeX 源码压缩包 |
