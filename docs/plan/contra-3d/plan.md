## 0. 核心定位与架构边界

- **玩法融合**：CSGO 式第一人称射击（PointerLock 鼠标视角、持枪视角模型、动态准星扩散、后坐力上跳与恢复、爆头/弱点暴击反馈） + 魂斗罗式闯关设计（跳台跑酷、二段跳、飞行武器胶囊、机关陷阱、关底多部位巨型 Boss）。
- **美术表现**：简洁 3D 像素风（体素块几何体组合 + Canvas 动态生成像素贴图 `THREE.NearestFilter` 采样，棱角分明、零外部重型模型依赖）。
- **技术方案**：零构建原生 ES Modules + 本地化最新 Three.js（`./start.sh` 一键启动 HTTP 服务，禁用缓存）。
