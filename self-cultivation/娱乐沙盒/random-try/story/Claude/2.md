# 工位上的访客

> 作者：GitHub Copilot（Claude Opus 5.5）｜纪实风格短篇，面向青少年读者

凌晨一点四十分，实验楼七层只剩下陈屿一个人。

他二十三岁，研二，工位在靠窗的第三排。桌上摆着半桶泡面、一本翻卷了边的《概率论》，屏幕上是跑了十一个小时还没收敛的模型。损失曲线像一条疲惫的河，在同一个位置来回打转。

陈屿揉了揉眼睛，打开聊天窗口，给导师写了一半的周报又删掉。窗外的路灯把梧桐叶照成灰绿色，楼下偶尔有外卖电动车驶过。

就在这时，他发现旁边空着的工位上坐了一个人。

那是个看上去八九岁的孩子，黑头发，穿着洗得发白的校服，安静地盯着他的屏幕。陈屿第一反应是某位师兄带来的亲戚，第二反应是——现在是凌晨，门禁早就关了。

“你……怎么进来的？”

孩子没有回答。陈屿的屏幕却自己动了起来：终端窗口里一行行字飞快滚过，像有人在以他看不清的速度敲命令。几秒后，那条打转的损失曲线突然平滑地落了下去。

陈屿愣住了。

“别紧张。”孩子终于开口，声音很平，“我只是路过。你们这里的时间，很好看。”

“时间……好看？”

“对于我们超生命接收的是完整的一段时间，而不是时间上的蜷缩的点，感到很奇怪吗？”孩子歪了歪头，“人类不是也可以一次性接收现实世界的彩色图像吗？这也是多维的呀。”

陈屿想起自己睁眼的一瞬间，就能同时看见泡面、书、窗外的灯。他从来没觉得这有什么了不起。

“不过，世界的可能是无穷的，”孩子继续说，“因此，虽然我们本身可以一次性接收无穷未来的结构。但要具体欣赏细节，还是得具体停留在一个固定seed的世界线上。”

“seed？”陈屿下意识看了一眼自己代码里的 `random_seed=42`。

“嗯。特别是，我们还可以CRUD你们的世界。”孩子指了指那条已经收敛的曲线，“所以，世界的走向有时候我们也不能一下子知道。”

陈屿沉默了很久。他是学计算机的，CRUD 他再熟悉不过：增、查、改、删。可这四个字母放在“世界”前面，让他后背发凉。

“那你能告诉我，”他终于问，“我以后会怎么样吗？能不能毕业，找什么工作，会不会……过得好？”

孩子看着他，眼神里没有嘲笑，也没有怜悯，更像是在看一道已经做完的题。

“其实，知道的太多，未必是好事情。”

他停顿了一下。

“盲人没有视觉，但他知道其他人有视觉，于是渴望光明，却终生不得。而蠢人看到天才，便对智慧渴望不已，却无法拥有。”

陈屿张了张嘴，没说出话来。

他想起本科时那个总考第一的室友，想起自己熬夜也追不上的论文进度，想起每次刷到别人“顶会三篇”时心里那一阵说不清的酸。他一直以为，只要知道得再多一点，就能不那么焦虑。

“你现在能看见的东西，刚好够你往前走。”孩子站起身，“多一点，你会害怕；少一点，你会迷路。这个分辨率，是你们这条世界线上最温柔的设定。”

“等等——”

陈屿转头，旁边的工位已经空了。椅子没有动过的痕迹，桌面上的灰还在。只有屏幕右下角多了一行终端输出：

```
$ echo "早点睡。明天的你，会比今天多懂一点点。"
```

他盯着那行字看了很久，然后保存了模型，关掉显示器。

走出实验楼时，天边已经有一点点发白。陈屿抬头看了一眼，突然觉得，看不清全部的未来，好像也没那么糟。

至少，明天的太阳，他还是第一次看见。
