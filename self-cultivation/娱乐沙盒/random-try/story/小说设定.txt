小说，就是一种想象力的创作。

首先是我最为喜爱的管理员设定: {
  - 拥有sandbox root and git权限，自由的创造、回退，前进，复制，fork，merge，clear等等。总之无所不能。
  其中最为奇妙之处在于，可以在主时空之外，创造一个小的复制sandbox，sandbox内的所有操作都不会影响主时空，甚至可以在sandbox内创造一个新的sandbox，形成无限递归的可能性。
  玩家可以随意操控sandbox内人物的行为，并且随意添加删除物品，何等自由！此想法灵感主要来自于nsfw内容创作。显然，我希望将一些不适合在主时空中出现的内容，放置在sandbox中进行创作。
  另一方面来说，这种设定富有高度的探索度，这无疑是一种游戏破解与创造的思想。如果在某个剧情中，尝试一些奇奇怪怪的操作，会发生什么呢？这种未知而富于想象力的好奇与探索欲望，是很有趣的。
}

sandbox设定的一个引申是agent系统: {
  主世界中，有一个完美无缺的agent负责行动。而我们则可以在sandbox世界里自由行动，享受自由的乐趣。一方面，这推进了主世界的和谐发展；另一方面，我们自身也可以在sandbox世界中探索一些也许非法的行为。
  此外，角色可以自由切换自身的性别、外貌、外形，从人类到更一般的类人生命，植物，非生命（岩石，水，空气，光球，行星，恒星）
}

然后是超生命设定: {
  普通的生命一般认为是对照现实宇宙的，只有三维几何感知，当然也包括一些额外的感知，例如嗅觉、味觉、听觉、触觉等等。超生命则是对照超现实宇宙的，拥有更多维度的感知能力。
  这就不得不提到维度分类了，我粗略将维度分为几何维度、属性维度（各种力场）、时间维度。
  超生命首先可以是高维几何感知的，例如四维、五维，在此之上就是无穷维几何感知。
  当然，既然是超生命，当然也需要装备一些超能力：心灵感应、念动力、瞬间移动、时空回溯、凭空造物、元素控制之类
}

无限幻想世界设定: {
  灵感来自于起点无限流，角色可以在不同的幻想世界中自由切换，例如仙侠、高武、科幻、都市等
  特别是，玩家可以干涉不同世界的关键剧情节点
}
