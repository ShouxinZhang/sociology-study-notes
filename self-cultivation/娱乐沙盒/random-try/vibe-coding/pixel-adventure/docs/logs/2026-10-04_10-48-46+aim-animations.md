# 开枪方向动画修复

- 任务 ID：`2026-10-04_10-48-46+aim-animations`
- 执行模型：Antigravity（Claude Opus 5.5）

## 用户原始 Prompt

> 嗯嗯，除此之外，我感觉，目前不同方向开枪的动画，还有问题，需要fix

> B

（B = 核心修复 + 边走边瞄腿部摆动）

## 诊断（修复前截图：`.agents/cache/pixel-adventure-aim/zoom.png`）

1. 非朝前方向只有一张静止图、没有枪口火光 → 看不出在开火。
2. 所有武器在上 / 斜 / 下方向共用一把“通用枪”。
3. 通用枪画法与朝前不统一：朝上枪从头里伸出遮住脸，斜上是细长棍，朝下像提桶，且无手臂。
4. 瞄准时腿固定为站姿，边走边瞄像滑行。

## 方案与边界

- 新增生成器 `tools/gen_aim_sprites.py`：从 `attack_<武器>` 帧抽出“前臂 + 枪”图层（与无武器姿势差分 + 握手区域），绕肩膀旋转到 5 个方向，与无腿上半身合成；火光绕中心旋转；腿部单独出 `legs_*` 图层。
- 参数唯一来源 `assets/data/aim.json`（肩膀坐标、各方向角度 / 平移、画布、身后部件）；`combat.js` 用同一份参数把武器 `muzzle` 绕肩膀旋转得到枪口，保证子弹从画出来的枪口射出。
- 朝上平移 5 px、朝下平移 3 px 并补手臂，避免挡脸 / 贴身。
- 近战武器动作不变。

## 风险与回滚

- 45° 旋转为最近邻采样，个别武器斜向略有锯齿；如需精修，调整 `aim.json` 或改生成器后重跑，不要手改 `aim.json` 精灵。
- 回滚：恢复 `contra.json` / `manifest.json` 备份，撤销 src 改动，删除 `tools/`、`assets/data/aim.json`、`assets/sprites/aim.json`。
