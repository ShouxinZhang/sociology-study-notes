# 原理 / 方法 / 技能 英语术语对照

> 来源：`random-writing/weekly/2026/2026-08-16--2026-08-22.md` 的 `2026-08-20 17:13:08 CST` 块。
> 用途：可复用的英文术语分层对照；周归档只保留入口链接。

| 分类层级 | 英文词汇 | 常用中文释义 | 核心侧重点与语境 | 典型搭配 / 示例 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 原理与底层逻辑**<br>*(Principles & Models)* | **Principle** | 原理、基本原则 | 根本性的客观规律、底层逻辑或做人准则 | *First principles (第一性原理), core principle* |
| | **Mental model** | 心智模型、思维模型 | 理解事物运转机制的认知框架 | *Build mental models, cognitive framework* |
| | **Heuristic** | 启发法、经验法则 | 用于快速决策的思维捷径（常用于科研/算法） | *Heuristic evaluation, search heuristic* |
| | **Rule of thumb** | 经验法则 | 虽不精确但极其实用的日常经验准则 | *A good rule of thumb is to...* |
| | **Paradigm** | 范式、理论体系 | 某一领域普遍公认的思维模式或世界观 | *Paradigm shift (范式转变), programming paradigm* |
| | **Tenet / Doctrine** | 信条、纲领 | 体系中的核心信条或指导教义 | *Core tenets of the philosophy* |
| **2. 战略与大方向**<br>*(Strategy & Pathways)* | **Strategy** | 战略、大方针 | 长期性、全局性、目标导向的顶层设计 | *Long-term strategy, corporate strategy* |
| | **Roadmap** | 路线图、实施路径 | 达成宏观目标的阶段性里程碑规划 | *Product roadmap, strategic roadmap* |
| | **Approach** | 切入方式、途径 | 面对问题时的观察视角或处理方针 | *A scientific approach, proactive approach* |
| **3. 方法与系统流程**<br>*(Frameworks & Systems)* | **Methodology** | 方法论、研究体系 | 理论化、成体系、可复现的研究或操作体系 | *Agile methodology, research methodology* |
| | **Framework** | 框架、分析模型 | 结构化的思考/落地脚手架 | *Conceptual framework, framework of analysis* |
| | **Method** | 方法、办法 | 达成特定目标的具体、系统化步骤 | *Scientific method, effective method* |
| | **Process / Protocol** | 流程 / 规程协议 | 需严格按顺序遵循的标准化作业步骤 | *Safety protocol, Standard Operating Procedure (SOP)* |
| | **Playbook** | 打法手册、行动指南 | 团队或业务中经过实战检验的一整套策略包 | *Sales playbook, go-to-market playbook* |
| | **Best practice** | 最佳实践 | 行业公认最有效、最规范的成熟做法 | *Industry best practice* |
| **4. 专业技能与造诣**<br>*(Skills & Craft)* | **Skill** | 技能、本领 | 通过系统学习与练习掌握的具体能力 | *Hard/soft skills, develop a skill* |
| | **Technique** | 技法、手法 | 规范、专业且具有针对性的实操技术 | *Laboratory technique, interview techniques* |
| | **Craft** | 手艺、工艺 | 强调精雕细琢、工匠精神的打磨过程 | *The craft of writing, master one's craft* |
| | **Know-how** | 实操诀窍、暗知识 | 实践中积累的、难以书面化的“行家门道” | *Technical know-how, domain know-how* |
| | **Expertise** | 专长、专业知识 | 在特定领域的深厚经验与高水平造诣 | *Domain expertise, subject-matter expertise* |
| | **Art** | 艺术、精妙之道 | 需要直觉、情商与悟性的高阶境界 | *The art of negotiation, the art of leadership* |
| **5. 捷径与实用妙招**<br>*(Tips & Hacks)* | **Trick** | 诀窍、小妙招 | 灵巧、聪明的小办法（有时略带戏法/偷懒色彩） | *A neat trick to save time, trade trick* |
| | **Hack** | 极客妙招、效率捷径 | 突破常规、能快速带来巨大提升的手段 | *Productivity hack, life hack* |
| | **Tip / Pointer** | 提示、小点拨 | 简短实用的经验传授 | *Helpful pointers, practical tips* |
| | **Knack** | 窍门、直觉天赋 | 凭手感或悟性掌握的熟练技巧 | *Have a knack for coding/design* |
| | **Shortcut** | 捷径、快径 | 缩短物理距离或办事时间的捷径 | *Keyboard shortcut, take a shortcut* |
| **6. 解决方案与应对**<br>*(Solutions & Fixes)* | **Solution** | 解决方案 | 彻底根治或化解问题的答案/方案 | *Comprehensive solution, optimal solution* |
| | **Workaround** | 变通方案、权宜之计 | 绕开障碍而非根治根本原因的应对策略 | *Temporary workaround, clever workaround* |
| | **Fix / Quick fix** | 修复 / 速效补丁 | 快速修补漏洞或应急解决的小手段 | *Quick fix, bug fix* |
| | **Countermeasure** | 对策、反制手段 | 针对潜在风险或外来威胁设立的防线 | *Security countermeasure, preventive measures* |
| | **Remedy** | 补救办法、良方 | 纠正偏差、挽回损失或消除不利影响的举措 | *Legal remedy, remedy the situation* |
