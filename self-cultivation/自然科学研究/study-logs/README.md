# Study Logs

Time fragmentation is a method of conducting scientific research that applies high-intensity interval techniques from sports science.

## 归档规范

- 每月一个文件：`YYYY-MM.md`，按时间顺序追加。
- 条目格式：`YYYY-MM-DD HH:MM:SS CST 类型+时长（内容）`；同一天的条目连续书写，不同日期空一行。
- 新月份开始时新建文件，并在下方索引登记。
